# AI MedCare - Diabetes Prediction System

## Overview

AI MedCare is a Machine Learning based web application developed using Flask. The system predicts diabetes risk based on patient medical data and generates a professional medical report with risk analysis and recommendations.

---

## Features

- AI-based Diabetes Prediction
- Machine Learning Model Integration
- Professional User Interface
- Patient Diagnosis Form
- Positive & Negative Result Pages
- Dynamic PDF Medical Report
- Admin Login System
- Admin Dashboard
- Patient History
- Search Patients
- Delete Patient Records
- Charts & Statistics
- SQLite Database
- Responsive Design

## Installation

Clone the repository

```
git clone <repository-url>
```

Install dependencies

```
pip install -r requirements.txt
```

Run the project

```
python app.py
```

Open browser

```
http://127.0.0.1:5000
```
